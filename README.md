# MP3 Converter

Быстрый конвертер любых аудиоформатов (m4a, wav, flac, aac, ogg, opus, wma, aiff и др.) в MP3. Работает офлайн, ffmpeg уже внутри.

## Как пользоваться
1. Перетащите файлы или папку в окно (или нажмите «Выбрать файлы…» / «Выбрать папку…»).
2. Выберите качество (по умолчанию 320 kbps).
3. Нажмите «Конвертировать». MP3 появится рядом с исходным файлом. Если такое имя занято — `имя (1).mp3`.

Теги и обложка сохраняются. Уже готовые MP3 пропускаются.

## Где скачать
На вкладке **Releases** (или Actions → последний запуск → Artifacts):
- `MP3-Converter-…-mac-x64.dmg` — Mac с процессором Intel
- `MP3-Converter-…-mac-arm64.dmg` — Mac на чипах M1–M4
- `MP3-Converter-…-win-x64.exe` — Windows (portable, без установки)

## Первый запуск
Приложение без платной подписи, поэтому система спросит подтверждение один раз.
- **Mac:** правой кнопкой по приложению → «Открыть» → «Открыть». Если пишет «повреждено», выполните в Терминале: `xattr -cr "/Applications/MP3 Converter.app"`
- **Windows:** «Подробнее» → «Выполнить в любом случае».

## Для разработчика
