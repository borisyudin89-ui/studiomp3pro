# Studio MP3 PRO

Быстрый конвертер любых аудиоформатов (m4a, wav, flac, aac, ogg, opus, wma, aiff и др.) в MP3. Работает офлайн, ffmpeg уже внутри.

## Как пользоваться
1. Перетащите файлы или папку в окно (или нажмите на поле, чтобы выбрать файлы; папку можно добавить кнопкой «+ Добавить папку…» внизу).
2. Выберите качество вверху справа (по умолчанию 320 kbps). Список файлов появляется внутри поля, при большом числе файлов он прокручивается.
3. Нажмите «Конвертировать». MP3 появится рядом с исходным файлом. Если такое имя занято — `имя (1).mp3`.

Файлы конвертируются параллельно. Теги и обложка сохраняются. Уже готовые MP3 пропускаются.

## Где скачать
Страница **Releases** этого репозитория:
- `Studio-MP3-PRO-…-mac-x64.dmg` — Mac с процессором Intel
- `Studio-MP3-PRO-…-mac-arm64.dmg` — Mac на чипах M1–M4
- `Studio-MP3-PRO-Setup-…-win-x64.exe` — Windows, установщик (ставится в один клик без прав администратора, создаёт ярлык на рабочем столе и в меню «Пуск»)

## Первый запуск
Приложение без платной подписи, поэтому система спросит подтверждение один раз.
- **Mac:** правой кнопкой по приложению → «Открыть» → «Открыть». Если пишет «повреждено», выполните в Терминале: `xattr -cr "/Applications/Studio MP3 PRO.app"`
- **Windows:** «Подробнее» → «Выполнить в любом случае».
